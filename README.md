# FazaHub — Cross-Platform Real-Time Communication App

**FazaHub** adalah aplikasi komunikasi web dan mobile lintas platform berbasis *real-time* yang dirancang untuk pertukaran pesan instan, berbagi media terkompresi, serta panggilan audio dan video secara langsung.

## Fitur Utama
- **Real-Time Messaging & Feed:** Pengiriman pesan instan dan pembaruan aktivitas secara *real-time* menggunakan sinkronisasi database.
- **Audio & Video Calling:** Panggilan suara dan video *peer-to-peer* yang stabil menggunakan **WebRTC** dan dukungan **TURN Server**.
- **Media Optimization:** Unggah dan kompresi gambar otomatis menggunakan **Cloudinary** untuk menjaga performa muat halaman tetap ringan.
- **Cross-Platform UI:** Antarmuka responsif untuk peramban web maupun perangkat mobile.

## Teknologi yang Digunakan (*Tech Stack*)
- **Web Frontend:** React, Vite, Tailwind CSS
- **Mobile App:** Flutter
- **Backend & Database:** Supabase (PostgreSQL, Realtime, Auth)
- **Real-Time Communication:** WebRTC (TURN Server)
- **Media Storage:** Cloudinary
